# Responsive Internship Board

A responsive internship listing website that helps students
discover internship opportunities across different domains.

## Features

- Internship listings
- Search internships
- Domain filtering
- Responsive design
- Accessible form labels
- Keyboard-friendly navigation
- Empty state
- Error state
- Mobile, tablet and desktop support

## Technologies

- HTML5
- CSS3
- JavaScript

## Responsive Testing

The project was tested at:

- 360px - Mobile
- 768px - Tablet
- Desktop width

## Project Structure

responsive-internship-board/

├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Open `index.html` in a browser.
4. Test the search and domain filter.
5. Test the website at different screen sizes.

## Search and Filter

Users can search internships by:

- Internship title
- Company name

Users can also filter internships by domain.
