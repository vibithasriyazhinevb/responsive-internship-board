# Responsive Internship Board

A responsive and accessible internship listing interface built using semantic HTML, CSS and vanilla JavaScript.

## Project Objective

The goal of this project is to build an accessible internship board that works across mobile, tablet and desktop screens without using a CSS or JavaScript framework.

---

## Features

- Responsive internship cards
- Internship search
- Domain filtering
- Work mode filtering
- Clear filters
- Internship details modal
- Apply Now interaction
- Loading state
- Empty state
- Error/retry state
- Keyboard navigation
- Escape key modal closing
- Focus trapping inside modal
- Visible focus indicators
- Semantic HTML
- Accessible form labels
- Mobile-first responsive design
- No horizontal scrolling at 360px
